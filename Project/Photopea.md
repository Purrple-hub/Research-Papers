# Photopea

> **The professional-grade photo editor that runs entirely in your browser**

Photopea is a free, surprisingly capable online image editor that brings professional-grade photo manipulation tools to the web. Whether you need to quickly crop a photo or design complex multi-layer graphics, Photopea handles it all—no downloads, no installations, no hassle. Supporting Adobe's native file formats including `.PSD`, `.AI`, and `.XD`, it's the ultimate browser-based alternative to expensive desktop software.

---

## 📋 Project Description

Photopea is an advanced image editor that works with both raster and vector graphics. Created by a small development team, it runs directly in your web browser using your device's own CPU and GPU. All files open instantly and never leave your device—there are no uploads to external servers.

From simple tasks like resizing images to complex workflows like designing webpages or editing multi-layer PSD files, Photopea offers a full suite of professional tools accessible to everyone. Its interface mirrors the familiar Photoshop workflow, making it easy for designers to transition, while its browser-based nature makes it perfect for Chromebooks, shared computer labs, and any situation where installing software isn't practical.

---

## ✨ Features

### Core Capabilities

- **Full PSD Support** – Open, edit, and save Photoshop `.PSD` files with layers, masks, and blend modes intact
- **Multi-Format Support** – Works with over 50 file formats including PNG, JPG, GIF, BMP, WEBP, SVG, PDF, AI, AVIF, DDS, HEIC, TIFF, MP4, TGA, CDR, PDN, EPS, INDD, Figma, and more
- **RAW Support** – Open DNG, CR2, CR3, NEF, ARW, RW2, RAF, ORF and FFF files with full adjustment controls
- **Layers & Masks** – Full layer management with layer groups, masks, layer styles (shadows, strokes, gradients, etc.)
- **Smart Objects & Adjustment Layers** – Work non-destructively with smart objects, adjustment layers, channels, and paths
- **Vector Graphics** – Create and edit vector graphics directly within the editor—perfect for logos, icons, and illustrations
- **Advanced Tools** – Liquify, Puppet Warp, Perspective Warp, Levels, Curves, Gaussian Blur, and more
- **Retouching Tools** – Spot Healing Brush, Healing Brush, Patch tool, and background removal

### AI-Powered Features (Premium)

- **Background Removal** – Remove backgrounds with one click
- **Generative Fill** – Replace any part of an image with new content through text descriptions

### Technical Highlights

- **Runs Locally** – All processing happens on your device—no uploads, no privacy concerns
- **Works Offline** – Once loaded, you can disconnect from the internet and continue editing
- **Cloud Storage Integration** – Save files directly to Dropbox, OneDrive, and Google Drive
- **Cross-Platform** – Works on any device with a modern browser—desktop, laptop, or mobile
- **Scriptable** – Supports Photoshop automation (`.ATN` files)

## 🚀 Quick Start

The fastest way to start editing with Photopea:

1. **Open your browser** and navigate to **[photopea.com](https://www.photopea.com/)**
2. **Drag and drop** any image, PSD, or supported file into the browser window
3. **Start editing** — the familiar Photoshop-like interface is ready to go
4. **Save your work** — export as PSD, PNG, JPG, or any of the 50+ supported formats

No account creation required. No downloads. No installations. Just open and edit.

## 💻 Usage Examples

### Example 1: Edit a Photoshop File

1. Go to **[photopea.com](https://www.photopea.com/)**
2. Drag your `.PSD` file into the browser window
3. All layers, masks, and blend modes load intact
4. Edit any layer, add adjustments, or apply filters
5. Save back as `.PSD` to preserve layers for collaboration

### Example 2: Remove a Background

1. Open your image in Photopea
2. Select the **Background Removal** tool (Premium feature)
3. Click once—the background is automatically removed
4. Export as PNG with transparency

### Example 3: Edit a RAW Photo

1. Drag a `.CR2`, `.NEF`, `.ARW`, or other RAW file into Photopea
2. Use the RAW conversion sliders to adjust Exposure, Color Balance, Contrast, Highlights, and Shadows
3. Apply further edits with layers and filters
4. Export as JPG, PNG, or PSD

### Example 4: Create Vector Graphics

1. Open Photopea and create a new document
2. Use the vector tools to draw shapes, paths, and curves
3. Apply fills, strokes, and gradients
4. Export as SVG or PSD

*For detailed tutorials, visit the [official learn page](https://www.photopea.com/learn/)*.

## 🧪 Running Tests

Photopea is a web-based application, not a traditional software library. However, you can validate your work by:

1. **Opening and saving files** – Test various formats (PSD, AI, SVG, RAW) to ensure compatibility
2. **Checking layer integrity** – Open a complex PSD and verify all layers, masks, and styles are preserved
3. **Using the community** – The [r/photopea](https://www.reddit.com/r/photopea) subreddit and [GitHub issues](https://github.com/photopea/photopea) are great places to report bugs and request features

For performance testing, Photopea's RAM usage has been optimized with reductions of 10% to 40%, particularly when using layer styles.
